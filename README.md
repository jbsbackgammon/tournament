# Tournament

eJBSの大会ソースを取り込み、トーナメント表を編集してPNGを書き出すブラウザツールです。共有された4点のデザインをもとに、左右の選手枠、赤い勝ち上がり線、灰色の敗退・BYE枠、中央の大会名とJBSロゴを配置します。

## 起動

Node.js 22以降を用意し、リポジトリで実行します。外部パッケージのインストールは不要です。

```sh
npm start
```

http://127.0.0.1:4173 を開きます。`file://` で直接開くのではなく、上記のサーバーまたはGitHub Pagesを利用してください。

## 使い方

1. eJBSのページソースを貼り付けて「取り込む」、または `.txt` を選択します。共有例の名人戦64枠・新鋭戦16枠を試すこともできます。
2. 手入力の場合は元の枠数を選び「新規作成」。1行1名の名簿も取り込めます。補足は選手名の後にタブ区切りで記入します。
3. 「選手・勝ち上がりを編集」でラウンドを選び、選手名を編集。「勝者」で次のラウンドに進めます。不戦勝枠は `BYE` と入力します。
4. 表示枠数で8・16・32・64を切り替えます。たとえば64枠の元データから16枠を選ぶと、ベスト16以降のみを表示し、元データは保持します。
5. 補足表示、5大タイトル優勝者、PNGサイズ・縦横を選び、PNGを書き出します。
6. 続けて編集する場合は「大会データを保存」でJSONを保存。「データを開く」で復元できます。

|形式|横向き|縦向き|解像度|
|---|---|---|---|
|A4|3508 × 2480 px|2480 × 3508 px|300dpi|
|A5|2480 × 1748 px|1748 × 2480 px|300dpi|
|フルHD|1920 × 1080 px|横向きのみ|96dpi|

A4・A5にはPNGのpHYsチャンクに300dpiを記録します。64枠表示では補足を非表示にしますが、入力した補足は保持します。64枠を小さい画面用画像に収めると文字は小さくなります。印刷用の縦向きも利用できます。

5大タイトルは、日本選手権・盤聖戦・名人戦・王位戦・賽王戦です。期数・タイトル名・優勝者を編集できます。優勝者名は現在の情報と誤認しないよう初期状態では空欄です。

## eJBS取り込み

- 共有された `eJBS例1.txt` / `eJBS例2.txt` の `getTourneyCallback({...})` をJSONとして解析します。貼り付けたHTMLやJavaScriptは実行しません。
- 元の各ラウンド、優勝者、ポイント設定を読み込みます。ポイント設定は大会データ内に保持し、参考デザインに合わせて画像には表示しません。
- 途中ラウンドの選手について、直前の両枠が空の場合は選手とBYEを補完します。
- 同名の複数エントリーを勝手に削除しません。必要なら編集画面でBYEなどに修正してください。元ソースと参考画像が異なる場合は、元ソースを優先します。
- 勝敗未確定の空枠は「未定」と表示します。BYEと未確定枠は区別します。
- 通常のページ画面を全選択したテキストだけでは対戦順を確実に復元できないため、勝ち上がり込みの取り込みにはページソースを利用してください。通常のテキスト入力は1行1名の名簿として扱います。
- 入力はブラウザ内で処理し、外部サーバーに送信しません。認証・共有データベースはありません。ページを離れる前にJSONを保存してください。

## GitHub Actions

`.github/workflows/ci.yml` はpush・pull request時に `npm test` と `npm run build` を実行し、静的サイトを `tournament-site` アーティファクトとして保存します。

GitHub Pagesへの初回公開：

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定。
2. **Actions → Deploy GitHub Pages → Run workflow** をmainで実行。
3. 完了後のURLはGitHub PagesのEnvironmentまたはSettings → Pagesで確認。

公開ワークフローは手動実行です。公開済みページへ変更を反映する際も同じ操作を行います。デプロイ前にテストとビルドを再実行し、mainからのみ公開します。利用するURLはすべて相対パスなので、`/tournament/` 配下でも動作します。

GitHub公式手順: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## 開発・確認

```sh
npm test
npm run build
```

ビルド出力は `dist/`。依存ライブラリなしのES modules、SVG、Canvasで構成しています。テストは共有ソースの解析、ベスト16抽出、不戦勝補完、勝者変更時の依存結果クリア、入力エスケープ、全枠数・出力形式の座標、PNGのdpiメタデータを検証します。

## 素材

- 参考デザイン：ユーザー提供の女王戦03、名人戦32、新鋭戦15、盤聖戦32の画像。画像そのものはリポジトリに含めません。
- JBSロゴ：共有eJBSソースにも記載された公式画像 https://ejbs.backgammon.or.jp/image/jbs-logo.jpg を使用。ロゴの権利はJBSに帰属します。
- `fixtures/`：ユーザー提供のeJBSソース例。読み込み・回帰テスト用。

日本語フォントには端末の游ゴシック・メイリオ等を使うため、端末によって字形はわずかに異なります。
